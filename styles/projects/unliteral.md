# Unliteral documentation and interface style

Load only when a consuming repository explicitly selects this profile for Unliteral
product documentation or its Telegram RU → EN pilot. Read the common style and
the profile for the selected output language as well.

- In Russian business requirements, use Russian concept names from the product
  glossary maintained in the product/ directory of the documentation repository.
- The interface language follows the client's locale. The Telegram RU → EN pilot
  uses Russian for navigation and explanations unless a specific UX document
  establishes otherwise.
- Documentation in the original Unliteral style uses Russian. Preserve that choice
  through a local documentation language override when adopting shared rules;
  PR titles, PR bodies and other artifacts retain their separately selected language.
