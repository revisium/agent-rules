# Requirement document style

Apply when writing REQ documents, unless local instructions specify another format.
Read the common style and the profile for the selected document language as well.

Write REQ as a specification.

- Number groups 1, 2, 3.
- Number items within each group 1.1, 1.2, 1.3.
- Give each item a short heading and one verifiable paragraph.
- Do not use separate "Requirement" and "Acceptance criteria" blocks.
- Replace "the system can" with concrete behavior or a user right.
- Replace vague words such as "suitable", "high-quality" and "convenient" with
  explicit criteria.
- Describe normal behavior directly, without rebutting unstated alternatives.
